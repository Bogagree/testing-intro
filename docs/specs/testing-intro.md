## Порядок работы

1. Заменить `test.todo` в четырёх файлах каталога. После каждого файла запускать `npm run test:catalog`.
2. Убедиться, что `npm run test:catalog` зелёный, а `npm run test:cart` всё ещё красный.
3. Реализовать пять функций в `src/cart.js`, пока `npm run test:cart` не станет зелёным.
4. Запустить `npm test` и `npm run test:coverage`.
5. Дописать в PR скриншот терминала с успешным `npm test` и скриншот `coverage/lcov-report/index.html`. Обновить самопроверку в описании PR.

## Часть 2. Корзина

Сигнатуры уже заданы тестами и `src/cart-app.js`. Меняем тела функций, экспорт и имена параметров не переименовываем так, чтобы сломать `require`.

```js
addToCart(cart, product, quantity) → cart
changeQuantity(cart, productId, quantity) → cart
removeFromCart(cart, productId) → cart
calculateCartSubtotal(cart) → number
calculateOrderTotal(cart, promoCode) → { subtotal, discount, delivery, total }
```

### addToCart

- Пустая корзина, наушники, количество 2 → одна строка с `quantity: 2` и полями товара.
- В корзине уже 1 пара наушников, добавляем 2 → `quantity: 3`.
- Количество `0` → `RangeError`.
- Лампа, остаток 3, добавляем 4 → `RangeError`.
- Второй другой товар дописываем новой строкой. Страница корзины добавляет по одному.

### changeQuantity

- Наушники с 1 до 4.
- Количество `0` → `RangeError`. Кнопка «−» на последней штуке тоже получит эту ошибку: страница вызывает `quantity - 1`.
- Количество 9 при остатке 8 → `RangeError`.
- ID `999` → корзина без изменений.

### removeFromCart

- Из корзины с наушниками и лампой удаление ID 1 оставляет лампу.
- Удаление единственного товара даёт `[]`.
- ID `999` оставляет корзину как была.

### calculateCartSubtotal

- `[]` → `0`.
- Лампа × 2 → `55800`.
- Наушники × 1 и лампа × 2 → `105700`.

### calculateOrderTotal

| Корзина | Промокод | subtotal | discount | delivery | total |
| --- | --- | --- | --- | --- | --- |
| лампа × 1 | `''` | 27900 | 0 | 30000 | 57900 |
| наушники × 2 | `''` | 99800 | 0 | 0 | 99800 |
| наушники × 1 | `SAVE10` | 49900 | 4990 | 30000 | 74910 |
| кабель 19900 × 1 | `SAVE10` | 19900 | 0 | 30000 | 49900 |
| наушники × 1 | `HELLO` | 49900 | 0 | 30000 | 79900 |

Порог доставки смотрит на сумму до скидки: у наушников × 1 сумма 49900, поэтому доставка платная даже со скидкой.
